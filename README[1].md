# Hari Dev — Portfolio Website

A cinematic portfolio website for Hari Dev, Professional Cinematographer & Visual Storyteller.

## 1. Add your images
Put your own images inside `assets/` and use these filenames:

- hero.jpg
- work-01.jpg
- work-02.jpg
- work-03.jpg
- photo-01.jpg ... photo-06.jpg
- film.jpg

Recommended:
- Hero: 1920x1080 or larger
- Portfolio photos: 1600px+ wide
- Compress JPG/WebP images for faster loading.

## 2. Edit contact details
Open `index.html` and replace:
- `yourmail@example.com`
- Instagram `#`
- WhatsApp `#`
- YouTube `#`

## 3. GitHub Pages
1. Create a GitHub repository, e.g. `hari-dev-portfolio`
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. GitHub → Settings → Pages
4. Source: Deploy from branch
5. Branch: `main` / root
6. Save.
7. Your website will get a GitHub Pages URL.

## Important
This is a front-end portfolio. No backend is required.
